# Netbook-DWM
a small dwm config i made for my netbook
---
# dependencies
- a samsung NC series netbook (NC210 NC110)
- dwm obviously
## the packages below
```
build-base
libx11-dev
libxft-dev
libxinerama-dev
dmenu
xterm
```
## optional:
```
xsetroot
acpi
feh
```
---

# Why?
### xsetroot - status bar text
### acpi - battery information
### feh - wallpaper management
